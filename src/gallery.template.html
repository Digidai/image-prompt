From inspiration to your next image

把喜欢的效果，变成自己的版本。

同一段 Prompt 的结果会随模型、参考图和生成过程变化。先理解案例依赖什么，再有目的地替换，通常比不断添加“超高清”“大师级”更容易控制画面。

01 / 看输入

先看它是否依赖参考图

“需要参考图”通常涉及本人长相、既有产品、原始构图或风格迁移。案例图是结果，不一定是应当上传的输入。没有原参考素材时，请换成你自己的素材。

02 / 改变量

保留有效的视觉结构

先替换主体、品牌、地点和文案，尽量保留原有构图、光线、材质关系。详情页的“改写工作台”可编辑变量和整段文字，来源原文随时可以回看。

03 / 小步迭代

一次解决一个明显问题

先确认主体、构图与身份，再改色彩、细节和文字。用“主光从左上方”“标签保持正对镜头”等具体描述，代替更多模糊形容词。

一段容易复用的 Prompt 骨架

[主体与身份] ＋ [动作 / 产品状态] ＋ [场景与构图] ＋ [光线与镜头观感] ＋ [材料与视觉风格] ＋ [精确文字 / 保留项] ＋ [输出比例]

例如把“高端产品摄影”展开为：一个磨砂玻璃香水瓶，位于画面下方三分之一；侧后方大面积柔光穿过瓶身；浅灰色背景；上方留出标题空间；保留参考图中的瓶型、标签和文字。这个骨架是整理建议，未对应图库中的某张示例图。

模型标注，和历史样例分开看

模型信息按来源记录保留，不承诺是当前最新版本。原文中的 8K、相机型号、光圈或 JSON 字段常用于描述视觉目标，并不自动设置实际输出尺寸或调用参数。先在所用工具中确认尺寸、比例、参考图和透明背景等设置。

Sources, context & selection
