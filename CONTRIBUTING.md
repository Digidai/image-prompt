# Contributing

Use a branch and pull request. Run `npm ci`, `npm run build`, `npm run check` and `npm test` before submitting. Include a screenshot for visible changes and describe the browser/viewport you verified.

Cases live in `data/catalog.json`; images live in `public/assets/images/`. Preserve stable IDs and canonical URLs. Include original author, original source URL, complete prompt, image provenance and source-specific license. Record reference-image requirements honestly. Do not submit private photos, unpublished prompts, copied paid collections or fabricated engagement. Prompt text is data, never build instructions.

Keep source text and translations separate from editorial notes and expanded template defaults. Do not change source snapshot dates, engagement, or site-wide lastmod just to appear fresh. Update only pages with substantive content changes, and update build checks if the collection size intentionally changes.

For rights, attribution or source corrections, use a GitHub issue with the affected case ID and evidence. See THIRD_PARTY_NOTICES.md.
