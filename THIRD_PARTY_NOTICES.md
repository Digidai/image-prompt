# Third-party content and attribution

The MIT license covers project code. It does not relicense third-party prompts, images or translations.

The supplied `Prompt_Atlas_2026-10-19.html` snapshot is the import source. Its SHA-256 and extraction changes are recorded in `data/import.json`. The repository retains author names, author links, original posts, collection links, full prompt text, source translations where available, image provenance, dates and source-specific licenses in `data/catalog.json`, HTML detail pages and Markdown exports.

Copies of the upstream license texts checked at launch are in `licenses/`. For GPT-4o cases, `fullAttribution`, `imageAuthor`, `generationTool` and per-case attribution URLs remain in the dataset. These collection examples were regenerated by the upstream maintainer with Sora; they are not necessarily the original post images. No examples were regenerated by this project.

Source prompts are preserved. Where an upstream template provides default variable values, both its original syntax and the expanded copyable form are retained. Preview images were decoded from the supplied HTML; that snapshot had resized and transcoded them to WebP. This project separates those previews into files with content hashes. Chinese curation, descriptions, categories and presentation are derived from the supplied atlas; current-model release claims were replaced with source-label explanations. Upstream endorsement is not implied.

Historical engagement and repository Stars are source-snapshot records, not current measurements, satisfaction scores or generation success rates. Repository license statements do not independently establish commercial rights to every depicted person, trademark, character or third-party work. Follow the individual source and any exception notice when reusing content. Keep attribution, link the source license and identify modifications.

For a correction, attribution request or rights-holder removal request, [open an issue](https://github.com/Digidai/image-prompt/issues). Include the relevant case ID, source and requested correction; do not upload private reference photos.
